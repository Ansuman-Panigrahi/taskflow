1. Git & GitHub
High priority

Learn only:
- Merge vs rebase
- Cherry-pick
- Revert vs reset
- Reflog and recovery
- Merge conflict resolution
- Pull Requests and code reviews
- Squash merge
- Branch protection
- Conventional commits
Skip Git Flow theory, bisect, advanced Git internals and rarely used commands.

2. Angular Unit Testing
High priority

- Jasmine and your Angular test runner
- TestBed
- Component and service testing
- Mocking dependencies and spies
- HTTP testing
- Testing asynchronous code
- Code coverage
Don't spend weeks chasing 100% coverage.

3. NgRx
High priority

- Store, Actions, Reducers
- Selectors and Effects
- RxJS operators in Effects
- NgRx Entity
- Store DevTools
- Loading and error state management
- SignalStore

4. Docker
High priority

- Images vs containers
- Dockerfile
- Multi-stage builds
- Docker Compose basics
- Nginx for Angular deployment
- Build, run, tag and publish images

5. GitHub Actions & CI/CD
High priority

- Workflow, jobs, steps and runners
- YAML configuration
- GitHub Secrets
- Dependency caching
- Automated lint, test and build
- Docker image publishing
- Basic deployment and rollback

6. Code Quality & Security
Learn basics

- ESLint and Prettier
- SonarQube and quality gates
- Dependency vulnerability scanning
- CSP and XSS fundamentals
- Lockfiles and dependency management
